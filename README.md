# Jay Simple Ruby Calculator

A simple command-line calculator written in Ruby. It supports addition, subtraction, multiplication, and division, and lets you quit at any time by typing `exit`.

## Requirements

- Ruby 2.7 or newer

## Run it

```bash
ruby calc.rb
```

## Example

```text
=== Jay Simple Ruby Calculator ===
Operations: +  -  *  /
Type 'exit' to quit

Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5
Result: 10 + 5 = 15.0

Enter first number: exit
Goodbye!
```
